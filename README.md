# 🏥 Pure Care Frontend

A modern, responsive, and multilingual frontend for **Pure Care**, a home healthcare provider serving **Alexandria, Egypt**.

The application is built with a **mobile-first** approach, focusing on performance, accessibility, and an intuitive user experience. It allows users to explore healthcare services, request home care, rent medical equipment, apply for careers, and quickly connect with the Pure Care team through phone or WhatsApp.

---

## ✨ Features

- 📱 Mobile-first responsive design
- 🌐 Arabic (RTL) & English (LTR) support
- 🩺 Dedicated pages for every healthcare service
- 🛠️ Medical equipment rental portal
- 🚑 Emergency assistance section
- 💬 Guided service request flow with WhatsApp integration
- 📞 Quick Call & WhatsApp actions
- 🎥 Company introduction video
- 💼 Careers page with application form
- ⭐ Testimonials
- ❓ Frequently Asked Questions
- ⚡ Optimized performance
- 🔍 SEO-friendly architecture
- ♿ Accessibility-focused UI

## 🚀 Getting Started

### Prerequisites

- Node.js >= 20
- npm / pnpm / yarn

### Installation

```bash
git clone https://github.com/your-username/purecare-frontend.git

cd purecare-frontend

npm install
```

### Start Development Server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## 🌍 Internationalization

The application supports:

- 🇺🇸 English (LTR)
- 🇪🇬 العربية (RTL)

Language is automatically detected from the user's browser and can be changed manually from the navigation menu.
